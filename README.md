# mini-rag


This is a minimal implementation of thr RAG model for quesition 
answering.
 
## Requirment

-Python 3.10

###### installing Python using MiniCoda

1) Download and install MiniConda from[here](https://docs.anaconda.com/free/miniconda/#quick-command-line-install)
2) Creat a new enviroment using the follwoing command:

 ```bash
$ conda create -n mini-rag python=3.10
```
3) Active the enviroment 
``` bash
$ conda active mini-rag
```
